# Checklist para testar o aplicativo publicado

- [ ] O Streamlit abre em aba anônima sem login.
- [ ] Os dois dashboards aparecem nas abas.
- [ ] O CSV aparece carregado e totaliza aproximadamente 1072 linhas.
- [ ] Selecionar zero, uma e várias variáveis no Dashboard 1 não causa erro.
- [ ] Slider de intervalo atualiza gráficos e número de registros.
- [ ] Selecionar gerações/tipos/categoria altera dados.
- [ ] Histograma aparece para cada variável selecionada.
- [ ] O heatmap aparece quando existem >= 2 variáveis.
- [ ] Um intervalo vazio produz aviso, não stack trace.
- [ ] Dashboard 2 mostra 3–5 métricas, **após configurar por decisão própria**.
- [ ] Dashboard 2 exibe três visuais quando as variáveis são escolhidas.
- [ ] `data/clean/dataset.csv` está versionado e não contém dados pessoais.
- [ ] URL final do Streamlit está no README.
- [ ] `prompts/DECLARACAO_IA.pdf` foi preenchido, assinado e entregue.
- [ ] Justificativa e rascunhos revisados pessoalmente pelo autor.
